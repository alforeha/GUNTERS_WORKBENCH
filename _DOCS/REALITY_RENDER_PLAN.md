# Reality Render — Current Plan

Status: **CURRENT** — controlling note for the Reality Render phase.
Supersedes `POINT_CLOUD_REALITY_VIEW_PLAN.md` (historical; do not delete) and
re-frames `DRAFT_3DGS.md` (historical; useful only under the corrected
architecture below).

## 1. Framing

1. **Reality Render is a derived visualization layer inside Reality
   Simulation.** It is one way of looking at simulation data.
2. **Reality Render is not the Reality Simulation itself.** The simulation
   remains the project-level, data-source-agnostic top-level manifest object.
3. **The first render source is measured point cloud data.** Not photos, not
   trained models.
4. **Indexed-full is the required next path.** Preview sampling was an honest
   stopgap; it is not sufficient for long-term Workbench trust. The reliable
   path is a full, lossless, streamable index of the measured source.
5. **Screen-space-error / tile streaming replaces crude near-camera
   densification.** The 2-nearest-leaf byte-range densification path is
   demoted to disclosed fallback where no index exists.
6. **Analytic splats/surfels are derived from source/indexed point data.**
   Attributes (radius, normal, confidence) are computed analytically from
   measured points. No photo training, no hallucinated infill.
7. **Points and splats/surfels remain toggleable.** The user can always
   return to the measured-point view.
8. **Source point picking/snapping must consult measured/indexed source
   data**, never derived splat approximations. (Snapping itself is NEXT-phase;
   this phase lays the data groundwork by keeping the index lossless.)
9. **Any derived render carries `derived` truth/status.** Always.
10. **Preview, indexed-full, and derived states are disclosed clearly** in the
    viewer at all times.

## 2. Index strategy decision (Phase 0, locked)

**WPI v1 (Workbench Point Index), internal, COPC-shaped. Real COPC deferred.**

- Octree tile index generated by streaming passes over the immutable LAS
  source in the Electron main process (worker thread; renderer never blocks).
- Node addressing `L-X-Y-Z` (COPC/EPT-style) so a later COPC phase changes the
  container format, not the architecture.
- Tiles store original int32 XYZ + source scale/offset (lossless), plus
  intensity u16, classification u8, returns u8, RGB u16×3 when present.
- Tiles are gzip-compressed (`zlib`), stored under `derived/<assetId>/index/`.
- Why not COPC now: no LAZ codec in the dependency tree; laz-perf WASM or
  bundled untwine/PDAL is the phase's largest packaging risk and is not needed
  to achieve honest indexed-full streaming. We do not claim COPC support.

## 3. Truth mapping (unchanged vocabulary)

| Data | Truth status |
|---|---|
| Original LAS/LAZ file | `source` (immutable) |
| WPI v1 index | `indexed-full` |
| Temporary preview cache | not an asset; disposable cache |
| Sampled display set | `preview-sampled` |
| Analytic splat/surfel render | `derived` |

## 4. Display-state disclosure model

The viewer banner must at all times distinguish:
- **Indexed-full streaming** — "Indexed-full — streaming N of M points · refining" /
  "settled".
- **Preview-sampled** — "Preview — sampled N of M".  No index exists; no densification
  active.
- **Densification fallback** — "Preview — sampled N of M · source densification
  fallback".  Only when no valid (complete, non-stale) WPI index exists for the asset.
  Densification is gated at the call site: if a valid index asset is present in the
  manifest with no managed-staleness warnings, the near-camera densification path does
  not fire.  A stale index (source-missing, header-sha/size/mtime changed) is treated as
  absent for this gate, so densification fallback remains available alongside the stale
  warning of Phase 1.
- **Derived render** — "Analytic surfel render (derived) — not measured
  points" whenever the derived layer is visible.

## 5. Invariants (must not regress)

Single primary Reality Simulation (top-level, strict); membership only in flat
arrays keyed by `simulationId`; `realitySimulation` stores no layer/feature/
flag IDs; truth/status on assets only; layer lifecycle `active|hidden|error`
separate from truth; sources immutable; derived regenerable; cache disposable;
save/reopen/restart fidelity; origin rebase for large survey coordinates; no
sampled or derived display presented as measured source truth.

## 6. Scope classification

- **NOW:** WPI v1.1 index model (voxel-decimated overview tiles for uniform coarse
  coverage) + generation; SSE tile streaming; densification demotion; indexed-full
  truth path; analytic surfel derived layer (model + minimal render); points⇄surfels
  toggle; disclosure; persistence; metrics.
- **NEXT:** source-snapped markers/polylines/measurements; region-based
  full-detail extraction; walk-mode prototype; continuous radius density.
- **RESERVED:** classification controls; transformation controls;
  edge-to-linework; DWG/DXF entry; texture-to-hatching; extraction review.
- **FUTURE:** parcels/PLSS/NGS/GIS; satellite imagery entry; mobile field
  reporting; photo association; client Viewer export.
